# Лабораторна робота №2: JUnit, стек і матриця

Варіант №2 — `Stack<T>`, варіант №7 — `Matrix`. Обидва класи містяться
в пакеті `ua.edu.lab2`, мають окремі тести JUnit 5 та не потребують меню чи `main()`.

## Вимоги та запуск

Потрібен JDK 17 або новіший та доступ до інтернету під час першого запуску.
Робоче середовище: Temurin JDK 25.0.1, компіляція з `release=17`.
Maven Wrapper завантажує Maven 3.9.11 автоматично; окремий Maven не потрібен.

У PowerShell перейти до папки проєкту:

```powershell
Set-Location 'D:\4 курс\Тестування ПЗ\lab_2\lab_2_code'
.\mvnw.cmd clean test
```

Запуск лише одного класу тестів:

```powershell
.\mvnw.cmd '-Dtest=StackTest' test
.\mvnw.cmd '-Dtest=MatrixTest' test
```

У Linux або macOS використовуйте `sh ./mvnw clean test`.
Версії залежностей зафіксовані: JUnit Jupiter 5.10.0, Surefire і Surefire Report
3.2.3, Maven Compiler Plugin 3.14.1. Звичайні результати тестів з’являються
в `target/surefire-reports/`; ця папка не відстежується Git.

## Стек

`Stack<T>` зберігає елементи у власному `ArrayList<T>` і реалізує LIFO:
останній доданий елемент повертається першим.

| Метод | Поведінка |
| --- | --- |
| `push(T value)` | Додає елемент; `null` спричиняє `NullPointerException` |
| `pop()` | Видаляє й повертає вершину |
| `peek()` | Повертає вершину без видалення |
| `size()` | Повертає кількість елементів |
| `isEmpty()` | Перевіряє, чи стек порожній |

`pop()` та `peek()` для порожнього стеку кидають `EmptyStackException`.

## Матриця

`Matrix(double[][] values)` створює незмінну матрицю та глибоко копіює масив.
`add(Matrix other)` повертає нову матрицю з поелементною сумою.
`get(row, column)` читає елемент, `getRows()` і `getColumns()` повертають розміри.
Індекси починаються з нуля.

Конструктор відхиляє `null`, порожню матрицю, порожні рядки, рядки `null`
та рядки різної довжини через `IllegalArgumentException`.
Цей самий виняток виникає при додаванні `null` або матриці іншого розміру.
Некоректні індекси спричиняють `IndexOutOfBoundsException`.
Для елементів використовуються стандартні операції Java над `double`.

## Тести та матеріали для наступного етапу

`StackTest` перевіряє LIFO, перегляд вершини, порожній стан, один елемент,
винятки, узагальнений тип і повторне використання стеку.
`MatrixTest` перевіряє квадратні й прямокутні матриці, розмір 1×1, нульову
матрицю, дробові та від’ємні значення, некоректні дані, межі індексів,
копіювання вхідного масиву та незмінність операндів. Допуск для чисел — `1e-9`.

Кожен тестовий клас використовує `@BeforeEach`, українські `@DisplayName`,
`assertThrows` та `assertAll`, містить щонайменше два позитивні й два межові сценарії.

Логи запусків зберігаються поруч із проєктом у `../evidence/`:

- `tests-initial-success.log` — перший успішний запуск усіх тестів;
- `tests-intentional-failure.log` — запуск із навмисно неправильним очікуванням;
- `tests-final-success.log` — усі тести після відновлення;
- `intentional-failure.diff` — точна тимчасова зміна тесту;
- `verification.json` — підсумок перевірки з кодами завершення та кількістю тестів.
